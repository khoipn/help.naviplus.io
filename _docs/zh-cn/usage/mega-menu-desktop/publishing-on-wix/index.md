# 大型菜单（桌面）——在 Wix 上发布

Navi+ 在 Wix 上作为**原生 Wix 应用市场应用**运行。**桌面大型菜单**附加到——或替换——你的网站主导航栏。在 Wix 上，你无需编写任何 CSS 选择器：Navi+ **为你自动填充放置选择器**。

> 其他平台：请参见[在 Shopify 上发布]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publishing-on-shopify/)、[在 WordPress 上发布]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publish-on-wordpress/)，或[Squarespace / Webflow / 其他]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publish-on-wordpress-woocommerce-wix-others/)。

---

## 步骤

1. **从 [Wix 应用市场](https://www.wix.com/app-market)安装 Navi+** ——它在你的 Wix 仪表板内打开，已连接到你的网站。
2. **构建你的大型菜单** ——请参见[大型菜单（桌面）——如何使用]({{ site.baseurl }}/docs/usage/mega-menu-desktop/how-to-use/)。
3. **选择放置并发布** ——在编辑器的发布面板中，选择是否**替换**你的原生菜单或**插入**大型菜单旁边，然后发布（状态：已发布）。

Navi+ 通过 Wix 的嵌入脚本自动嵌入并自动应用放置——无需代码，无需主题编辑。

---

## 放置选择器是自动的

因为大型菜单附加到你的网站标题，Navi+ 需要知道在哪里。Wix 网站共享相同的底层结构（"Thunderbolt"运行时），所以 **Navi+ 已经知道你的标题和主菜单元素**并为你填充放置选择器。你只需在发布面板中选择**替换**或**插入**——无需编写 CSS，无需编辑主题代码。
