# 滑动菜单——在 Wix 上发布

Navi+ 在 Wix 上作为**原生 Wix 应用市场应用**运行。**滑动菜单**（又称汉堡菜单）从侧面滑入，是移动设备上深菜单树的主要导航。在 Wix 上，你无需编写任何 CSS 选择器：Navi+ **为你自动填充汉堡菜单触发器**。

> 其他平台：请参见[在 Shopify 上发布]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/publishing-on-shopify/)、[在 WordPress 上发布]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/publish-on-wordpress/)，或[Squarespace / Webflow / 其他]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/publish-on-wordpress-woocommerce-wix-others/)。

---

## 步骤

1. **从 [Wix 应用市场](https://www.wix.com/app-market)安装 Navi+** ——它在你的 Wix 仪表板内打开，已连接到你的网站。
2. **构建你的滑动菜单** ——请参见[滑动菜单——如何使用]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/how-to-use/)。
3. **发布** ——编辑器的发布面板为你自动定位现有汉堡菜单按钮；只需发布（状态：已发布）。

Navi+ 通过 Wix 的嵌入脚本自动嵌入并自动连接触发器——无需代码，无需主题编辑。

---

## 触发器是自动的

因为滑动菜单从按钮打开，Navi+ 需要知道是哪个按钮。Wix 网站共享相同的底层结构（"Thunderbolt"运行时），所以 **Navi+ 已经知道你的移动菜单按钮**并为你填充触发器选择器。如果你希望从不同的元素打开菜单，你可以在发布面板中覆盖目标。
