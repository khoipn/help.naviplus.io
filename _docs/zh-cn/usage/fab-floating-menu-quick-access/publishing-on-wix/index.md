# FAB——在 Wix 上发布

Navi+ 在 Wix 上作为**原生 Wix 应用市场应用**运行。**FAB**（浮动操作按钮）是一个**粘性**菜单——一个浮动快捷方式，在访客滚动时固定在视口的角落。在 Wix 上，一旦你安装 Navi+ 并发布 FAB，它就会**在整个网站范围内自动渲染**——无需粘贴代码，无需自定义代码步骤。

> 其他平台：请参见[在 Shopify 上发布]({{ site.baseurl }}/docs/usage/fab-floating-menu-quick-access/publishing-on-shopify/)、[在 WordPress 上发布]({{ site.baseurl }}/docs/usage/fab-floating-menu-quick-access/publish-on-wordpress/)，或[Squarespace / Webflow / 其他]({{ site.baseurl }}/docs/usage/fab-floating-menu-quick-access/publish-on-wordpress-woocommerce-wix-others/)。

---

## 步骤

1. **从 [Wix 应用市场](https://www.wix.com/app-market)安装 Navi+** ——它在你的 Wix 仪表板内打开，已连接到你的网站。Wix 负责身份验证，所以无需设置 API 密钥。
2. **构建你的 FAB** ——选择 **FAB** 布局并添加你的快速操作（联系、购物车、回到顶部等）。请参见[FAB——如何使用]({{ site.baseurl }}/docs/usage/fab-floating-menu-quick-access/how-to-use/)。
3. **发布菜单**（状态：已发布，而不是草稿）。

就这么简单。Navi+ 通过 Wix 的嵌入脚本自动嵌入到你的实时 Wix 网站中，FAB 立即出现在每一页上——无需代码片段，无需主题编辑。

---

## 将 FAB 限制在特定页面

在 Navi+ 编辑器中限制 FAB 的范围：

- **显示规则 → URL 模式** ——仅在匹配的 URL 上显示 FAB。
- **显示规则 → 设备** ——仅限制在移动设备或桌面。
- **显示规则 → 访客状态** ——仅限制登录用户等。

规则在浏览器中评估，所以更改会在下一页加载时应用。
