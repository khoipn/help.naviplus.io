# 网格菜单——在 Wix 上发布

Navi+ 在 Wix 上作为**原生 Wix 应用市场应用**运行。**网格菜单**是一个分割菜单——一个可点击瓷砖块，你可以将其放在页面内或附加到你的导航栏。在 Wix 上，你无需编写任何 CSS 选择器：Navi+ **为你自动填充放置选择器**。

> 其他平台：请参见[在 Shopify 上发布]({{ site.baseurl }}/docs/usage/grid-menu/publishing-on-shopify/)、[在 WordPress 上发布]({{ site.baseurl }}/docs/usage/grid-menu/publish-on-wordpress/)，或[Squarespace / Webflow / 其他]({{ site.baseurl }}/docs/usage/grid-menu/publish-on-wordpress-woocommerce-wix-others/)。

---

## 步骤

1. **从 [Wix 应用市场](https://www.wix.com/app-market)安装 Navi+** ——它在你的 Wix 仪表板内打开，已连接到你的网站。
2. **构建你的网格菜单** ——请参见[网格菜单——如何使用]({{ site.baseurl }}/docs/usage/grid-menu/how-to-use/)。
3. **选择放置并发布** ——选择网格应显示的位置（在目标处插入，或附加到你的导航栏），然后发布（状态：已发布）。

Navi+ 通过 Wix 的嵌入脚本自动嵌入并自动应用放置——无需代码，无需主题编辑。

---

## 放置是自动的

因为网格菜单放在你的网站上的某个位置，Navi+ 需要知道在哪里。Wix 网站共享相同的底层结构（"Thunderbolt"运行时），所以 **Navi+ 已经知道你的标题和主要内容区域**并为你填充放置选择器。在发布面板中选择**插入**或**替换**——无需编写 CSS。
