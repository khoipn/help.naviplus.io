# Publish on Wix

> 💡 New to Navi+ on Wix? See the [Navi+ on Wix overview](https://naviplus.io/blogs/compare/topic/naviplus-on-wix/) on naviplus.io.

Navi+ runs on Wix as a **native Wix App Market app**. A **mobile Mega Menu** opens from your site's mobile menu (hamburger) button. On Wix you don't write any CSS selectors: Navi+ **auto-fills the hamburger trigger for you**.

> Other platforms: see [Publish on Shopify]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publishing-on-shopify/), [Publish on WordPress]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publish-on-wordpress/), or [Squarespace / Webflow / others]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publish-on-wordpress-woocommerce-wix-others/).

---

## Steps

1. **Install Navi+ from the [Wix App Market](https://www.wix.com/app-market)** — it opens inside your Wix dashboard, already connected to your site.
2. **Build your mobile Mega Menu** — see [Mega Menu (Mobile) — How to use]({{ site.baseurl }}/docs/usage/mega-menu-mobile/how-to-use/).
3. **Publish** — the editor's publish panel targets your existing hamburger button for you; just publish (status: Published).

Navi+ embeds itself through Wix's Embedded Script and wires up the trigger automatically — no code, no theme edit.

---

## The trigger is automatic

Because a mobile Mega Menu opens from a button, Navi+ needs to know which one. Wix sites share the same underlying structure (the "Thunderbolt" runtime), so **Navi+ already knows your mobile menu button** and fills the trigger selector in for you. If you'd rather open the menu from a different element, you can override the target in the publish panel.
