# Mega Menu (Desktop) — Publish on Wix

Navi+ runs on Wix as a **native Wix App Market app**. A **desktop Mega Menu** attaches to — or replaces — your site's main navigation bar. On Wix you don't write any CSS selectors: Navi+ **auto-fills the placement selectors for you**.

> Other platforms: see [Publish on Shopify]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publishing-on-shopify/), [Publish on WordPress]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publish-on-wordpress/), or [Squarespace / Webflow / others]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publish-on-wordpress-woocommerce-wix-others/).

---

## Steps

1. **Install Navi+ from the [Wix App Market](https://www.wix.com/app-market)** — it opens inside your Wix dashboard, already connected to your site.
2. **Build your Mega Menu** — see [Mega Menu (Desktop) — How to use]({{ site.baseurl }}/docs/usage/mega-menu-desktop/how-to-use/).
3. **Choose placement and publish** — in the editor's publish panel, choose whether to **replace** your native menu or **insert** the Mega Menu next to it, then publish (status: Published).

Navi+ embeds itself through Wix's Embedded Script and applies the placement automatically — no code, no theme edit.

---

## Placement selectors are automatic

Because a Mega Menu attaches to your site's header, Navi+ needs to know where. Wix sites all share the same underlying structure (the "Thunderbolt" runtime), so **Navi+ already knows your header and main-menu elements** and fills the placement selectors in for you. You simply pick **replace** or **insert** in the publish panel — there is no CSS to write and no theme code to edit.
