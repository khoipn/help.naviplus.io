# Publish on Wix

> 💡 New to Navi+ on Wix? See the [Navi+ on Wix overview](https://naviplus.io/blogs/compare/topic/naviplus-on-wix/) on naviplus.io.

Navi+ runs on Wix as a **native Wix App Market app**. The **FAB** (floating action button) is a **sticky** menu — a floating shortcut that stays pinned to the corner of the viewport as visitors scroll. On Wix, once you install Navi+ and publish the FAB, it renders **site-wide automatically** — there is no code to paste and no Custom Code step.

> Other platforms: see [Publish on Shopify]({{ site.baseurl }}/docs/usage/fab-floating-menu-quick-access/publishing-on-shopify/), [Publish on WordPress]({{ site.baseurl }}/docs/usage/fab-floating-menu-quick-access/publish-on-wordpress/), or [Squarespace / Webflow / others]({{ site.baseurl }}/docs/usage/fab-floating-menu-quick-access/publish-on-wordpress-woocommerce-wix-others/).

---

## Steps

1. **Install Navi+ from the [Wix App Market](https://www.wix.com/app-market)** — it opens inside your Wix dashboard, already connected to your site. Wix handles authentication, so there are no API keys to set up.
2. **Build your FAB** — pick the **FAB** layout and add your quick actions (contact, cart, back-to-top, etc.). See [FAB — How to use]({{ site.baseurl }}/docs/usage/fab-floating-menu-quick-access/how-to-use/).
3. **Publish the menu** (status: Published, not Draft).

That's it. Navi+ embeds itself on your live Wix site through Wix's Embedded Script, and the FAB appears on every page immediately — no snippet, no theme edit.

---

## Restricting the FAB to specific pages

Scope the FAB inside the Navi+ editor:

- **Display rules → URL pattern** — show the FAB only on matching URLs.
- **Display rules → Device** — restrict to mobile or desktop.
- **Display rules → Visitor state** — restrict to logged-in users, etc.

Rules are evaluated in the browser, so changes apply on the next page load.
