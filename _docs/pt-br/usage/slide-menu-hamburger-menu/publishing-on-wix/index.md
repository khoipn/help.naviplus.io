# Slide Menu — Publicar no Wix

Navi+ funciona no Wix como um **aplicativo nativo do Wix App Market**. Um **Slide Menu** (também conhecido como menu hambúrguer) desliza pela lateral e é a navegação mais robusta para árvores de menu profundas em dispositivos móveis. No Wix você não escreve nenhum seletor CSS: Navi+ **preenche automaticamente o gatilho do hambúrguer para você**.

> Outras plataformas: veja [Publicar no Shopify]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/publishing-on-shopify/), [Publicar no WordPress]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/publish-on-wordpress/), ou [Squarespace / Webflow / outros]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/publish-on-wordpress-woocommerce-wix-others/).

---

## Etapas

1. **Instale Navi+ no [Wix App Market](https://www.wix.com/app-market)** — ele abre dentro do seu painel Wix, já conectado ao seu site.
2. **Crie seu Slide Menu** — veja [Slide Menu — Como usar]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/how-to-use/).
3. **Publique** — o painel de publicação do editor direciona seu botão hambúrguer existente para você; apenas publique (status: Publicado).

Navi+ se incorpora automaticamente através do Embedded Script do Wix e conecta o gatilho automaticamente — sem código, sem edição de tema.

---

## O gatilho é automático

Como um Slide Menu abre a partir de um botão, Navi+ precisa saber qual é. Os sites do Wix compartilham a mesma estrutura subjacente (o runtime "Thunderbolt"), portanto **Navi+ já conhece seu botão de menu móvel** e preenche o seletor de gatilho para você. Se preferir abrir o menu a partir de um elemento diferente, você pode substituir o alvo no painel de publicação.
