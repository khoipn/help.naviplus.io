# Publicar no Wix

> 💡 Novo no Navi+ no Wix? Veja a [visão geral do Navi+ no Wix](https://naviplus.io/pt/blogs/compare/topic/naviplus-on-wix/) no naviplus.io.

Navi+ funciona no Wix como um **aplicativo nativo do Wix App Market**. A **Tab Bar** é um menu **fixo** — ela se ancora à janela de visualização (geralmente perto da parte inferior em dispositivos móveis) e permanece no lugar enquanto os visitantes rolam. No Wix, uma vez que você instala Navi+ e publica a Tab Bar, ela é renderizada **automaticamente em todo o site** — não há código para colar e nenhuma etapa de Código Personalizado.

> Outras plataformas: veja [Publicar no Shopify]({{ site.baseurl }}/docs/usage/tabbar-bottom-navigation/publishing-on-shopify/), [Publicar no WordPress]({{ site.baseurl }}/docs/usage/tabbar-bottom-navigation/publish-on-wordpress/), ou [Squarespace / Webflow / outros]({{ site.baseurl }}/docs/usage/tabbar-bottom-navigation/publish-on-wordpress-woo-wix-others/).

---

## Etapas

1. **Instale Navi+ no [Wix App Market](https://www.wix.com/app-market)** — ele abre dentro do seu painel Wix, já conectado ao seu site. O Wix cuida da autenticação, então não há chaves de API para configurar.
2. **Crie sua Tab Bar** — escolha o layout **Tab Bar** e adicione 3–5 destinos principais. Veja [Tab Bar — Como usar]({{ site.baseurl }}/docs/usage/tabbar-bottom-navigation/how-to-use/) para dicas de design.
3. **Publique o menu** (status: Publicado, não Rascunho).

É isso. Navi+ se incorpora automaticamente ao seu site Wix ativo através do Embedded Script do Wix, e a Tab Bar aparece em cada página imediatamente — sem snippet, sem edição de tema.

---

## Restringir a Tab Bar a páginas específicas

Escope a Tab Bar dentro do editor Navi+ — não tente remover o aplicativo:

- **Display rules → URL pattern** — mostrar a Tab Bar apenas em URLs que correspondam a um padrão (por ex. `/shop/*`).
- **Display rules → Device** — restringir apenas a dispositivos móveis.
- **Display rules → Visitor state** — restringir a usuários conectados, etc.

As regras são avaliadas no navegador, então as alterações se aplicam no próximo carregamento de página.

## Faturamento

Navi+ no Wix é faturado através do **Wix** — um nível gratuito mais planos **Starter, Business e Elite**, cobrados junto com sua assinatura Wix. Atualize a partir da tela de preços dentro do aplicativo.
