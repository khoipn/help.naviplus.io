# Mega Menu (Mobile) — Publicar no Wix

Navi+ funciona no Wix como um **aplicativo nativo do Wix App Market**. Um **Mega Menu móvel** abre a partir do botão de menu móvel (hambúrguer) do seu site. No Wix você não escreve nenhum seletor CSS: Navi+ **preenche automaticamente o gatilho do hambúrguer para você**.

> Outras plataformas: veja [Publicar no Shopify]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publishing-on-shopify/), [Publicar no WordPress]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publish-on-wordpress/), ou [Squarespace / Webflow / outros]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publish-on-wordpress-woocommerce-wix-others/).

---

## Etapas

1. **Instale Navi+ no [Wix App Market](https://www.wix.com/app-market)** — ele abre dentro do seu painel Wix, já conectado ao seu site.
2. **Crie seu Mega Menu móvel** — veja [Mega Menu (Mobile) — Como usar]({{ site.baseurl }}/docs/usage/mega-menu-mobile/how-to-use/).
3. **Publique** — o painel de publicação do editor direciona seu botão hambúrguer existente para você; apenas publique (status: Publicado).

Navi+ se incorpora automaticamente através do Embedded Script do Wix e conecta o gatilho automaticamente — sem código, sem edição de tema.

---

## O gatilho é automático

Como um Mega Menu móvel abre a partir de um botão, Navi+ precisa saber qual é. Os sites do Wix compartilham a mesma estrutura subjacente (o runtime "Thunderbolt"), portanto **Navi+ já conhece seu botão de menu móvel** e preenche o seletor de gatilho para você. Se preferir abrir o menu a partir de um elemento diferente, você pode substituir o alvo no painel de publicação.
