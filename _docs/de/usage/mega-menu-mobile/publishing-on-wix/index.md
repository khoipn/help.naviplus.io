# Auf Wix veröffentlichen

> 💡 Neu bei Navi+ auf Wix? Siehe die [Navi+ auf Wix – Übersicht](https://naviplus.io/de/blogs/compare/topic/naviplus-on-wix/) auf naviplus.io.

Navi+ läuft auf Wix als **native Wix App Market-App**. Ein **Mobile Mega Menu** wird von deinem Website-Mobile-Menü (Hamburger) geöffnet. Auf Wix musst du keine CSS-Selektoren schreiben: Navi+ **füllt den Hamburger-Trigger automatisch für dich aus**.

> Andere Plattformen: siehe [Auf Shopify veröffentlichen]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publishing-on-shopify/), [Auf WordPress veröffentlichen]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publish-on-wordpress/), oder [Squarespace / Webflow / Sonstiges]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publish-on-wordpress-woocommerce-wix-others/).

---

## Schritte

1. **Installiere Navi+ aus dem [Wix App Market](https://www.wix.com/app-market)** — es öffnet sich in deinem Wix-Dashboard, bereits mit deiner Website verbunden.
2. **Erstelle dein Mobile Mega Menu** — siehe [Mega Menu (Mobile) — So wird´s verwendet]({{ site.baseurl }}/docs/usage/mega-menu-mobile/how-to-use/).
3. **Veröffentliche** — der Veröffentlichungsbereich des Editors zielt auf deinen bestehenden Hamburger-Button für dich; veröffentliche einfach (Status: Veröffentlicht).

Navi+ bettet sich über Wix's Embedded Script ein und verbindet den Trigger automatisch — kein Code, kein Theme-Edit.

---

## Der Trigger ist automatisch

Da ein Mobile Mega Menu von einem Button geöffnet wird, muss Navi+ wissen, welcher. Wix-Websites teilen sich alle die gleiche zugrunde liegende Struktur (die "Thunderbolt"-Laufzeitumgebung), daher **kennt Navi+ bereits deinen Mobile-Menu-Button** und füllt den Trigger-Selector für dich aus. Falls du das Menü lieber von einem anderen Element öffnen möchtest, kannst du das Ziel im Veröffentlichungsbereich überschreiben.

---

## Abrechnung

Navi+ auf Wix wird über **Wix** abgerechnet — eine kostenlose Stufe plus **Starter-, Business- und Elite**-Pläne, zusammen mit deinem Wix-Abonnement berechnet.
