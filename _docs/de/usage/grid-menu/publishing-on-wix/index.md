# Grid Menu — Auf Wix veröffentlichen

Navi+ läuft auf Wix als **native Wix App Market-App**. Ein **Grid Menu** ist ein Bereichsmenü — ein Block von Kacheln, die du in eine Seite platzierst oder an deine Navigation anhängst. Auf Wix musst du keine CSS-Selektoren schreiben: Navi+ **füllt die Placement-Selektoren automatisch für dich aus**.

> Andere Plattformen: siehe [Auf Shopify veröffentlichen]({{ site.baseurl }}/docs/usage/grid-menu/publishing-on-shopify/), [Auf WordPress veröffentlichen]({{ site.baseurl }}/docs/usage/grid-menu/publish-on-wordpress/), oder [Squarespace / Webflow / Sonstiges]({{ site.baseurl }}/docs/usage/grid-menu/publish-on-wordpress-woocommerce-wix-others/).

---

## Schritte

1. **Installiere Navi+ aus dem [Wix App Market](https://www.wix.com/app-market)** — es öffnet sich in deinem Wix-Dashboard, bereits mit deiner Website verbunden.
2. **Erstelle dein Grid Menu** — siehe [Grid Menu — So wird´s verwendet]({{ site.baseurl }}/docs/usage/grid-menu/how-to-use/).
3. **Wähle die Platzierung und veröffentliche** — wähle, wo das Grid erscheinen soll (an einem Ziel einfügen oder an deine Navigation anhängen), und veröffentliche dann (Status: Veröffentlicht).

Navi+ bettet sich über Wix's Embedded Script ein und wendet die Platzierung automatisch an — kein Code, kein Theme-Edit.

---

## Die Platzierung ist automatisch

Da ein Grid Menu an eine bestimmte Stelle auf deiner Website platziert wird, muss Navi+ wissen, wo. Wix-Websites teilen sich alle die gleiche zugrunde liegende Struktur (die "Thunderbolt"-Laufzeitumgebung), daher **kennt Navi+ bereits deine Header- und Hauptinhaltsbereich** und füllt die Placement-Selektoren für dich aus. Wähle **einfügen** oder **ersetzen** im Veröffentlichungsbereich — es gibt kein CSS zum Schreiben.

---

## Abrechnung

Navi+ auf Wix wird über **Wix** abgerechnet — eine kostenlose Stufe plus **Starter-, Business- und Elite**-Pläne, zusammen mit deinem Wix-Abonnement berechnet.
