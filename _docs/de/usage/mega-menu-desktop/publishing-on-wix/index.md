# Auf Wix veröffentlichen

> 💡 Neu bei Navi+ auf Wix? Siehe die [Navi+ auf Wix – Übersicht](https://naviplus.io/de/blogs/compare/topic/naviplus-on-wix/) auf naviplus.io.

Navi+ läuft auf Wix als **native Wix App Market-App**. Ein **Desktop Mega Menu** wird an — oder ersetzt — deine Website-Navigationsleiste. Auf Wix musst du keine CSS-Selektoren schreiben: Navi+ **füllt die Placement-Selektoren automatisch für dich aus**.

> Andere Plattformen: siehe [Auf Shopify veröffentlichen]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publishing-on-shopify/), [Auf WordPress veröffentlichen]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publish-on-wordpress/), oder [Squarespace / Webflow / Sonstiges]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publish-on-wordpress-woocommerce-wix-others/).

---

## Schritte

1. **Installiere Navi+ aus dem [Wix App Market](https://www.wix.com/app-market)** — es öffnet sich in deinem Wix-Dashboard, bereits mit deiner Website verbunden.
2. **Erstelle dein Mega Menu** — siehe [Mega Menu (Desktop) — So wird´s verwendet]({{ site.baseurl }}/docs/usage/mega-menu-desktop/how-to-use/).
3. **Wähle die Platzierung und veröffentliche** — wähle im Veröffentlichungsbereich des Editors, ob du dein natives Menü **ersetzen** oder das Mega Menu daneben **einfügen** möchtest, und veröffentliche dann (Status: Veröffentlicht).

Navi+ bettet sich über Wix's Embedded Script ein und wendet die Platzierung automatisch an — kein Code, kein Theme-Edit.

---

## Placement-Selektoren sind automatisch

Da ein Mega Menu an die Header-Navigation deiner Website angehängt wird, muss Navi+ wissen, wo. Wix-Websites teilen sich alle die gleiche zugrunde liegende Struktur (die "Thunderbolt"-Laufzeitumgebung), daher **kennt Navi+ bereits deine Header- und Hauptmenü-Elemente** und füllt die Placement-Selektoren für dich aus. Du wählst einfach **ersetzen** oder **einfügen** im Veröffentlichungsbereich — es gibt kein CSS zum Schreiben und keinen Theme-Code zu bearbeiten.

---

## Abrechnung

Navi+ auf Wix wird über **Wix** abgerechnet — eine kostenlose Stufe plus **Starter-, Business- und Elite**-Pläne, zusammen mit deinem Wix-Abonnement berechnet.
