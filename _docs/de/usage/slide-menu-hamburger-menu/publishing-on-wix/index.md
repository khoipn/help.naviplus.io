# Slide Menu — Auf Wix veröffentlichen

Navi+ läuft auf Wix als **native Wix App Market-App**. Ein **Slide Menu** (auch Hamburger-Menü genannt) gleitet von der Seite herein und ist das Arbeitstier der Navigation für tiefe Menübäume auf Mobile. Auf Wix musst du keine CSS-Selektoren schreiben: Navi+ **füllt den Hamburger-Trigger automatisch für dich aus**.

> Andere Plattformen: siehe [Auf Shopify veröffentlichen]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/publishing-on-shopify/), [Auf WordPress veröffentlichen]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/publish-on-wordpress/), oder [Squarespace / Webflow / Sonstiges]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/publish-on-wordpress-woocommerce-wix-others/).

---

## Schritte

1. **Installiere Navi+ aus dem [Wix App Market](https://www.wix.com/app-market)** — es öffnet sich in deinem Wix-Dashboard, bereits mit deiner Website verbunden.
2. **Erstelle dein Slide Menu** — siehe [Slide Menu — So wird´s verwendet]({{ site.baseurl }}/docs/usage/slide-menu-hamburger-menu/how-to-use/).
3. **Veröffentliche** — der Veröffentlichungsbereich des Editors zielt auf deinen bestehenden Hamburger-Button für dich; veröffentliche einfach (Status: Veröffentlicht).

Navi+ bettet sich über Wix's Embedded Script ein und verbindet den Trigger automatisch — kein Code, kein Theme-Edit.

---

## Der Trigger ist automatisch

Da ein Slide Menu von einem Button geöffnet wird, muss Navi+ wissen, welcher. Wix-Websites teilen sich alle die gleiche zugrunde liegende Struktur (die "Thunderbolt"-Laufzeitumgebung), daher **kennt Navi+ bereits deinen Mobile-Menu-Button** und füllt den Trigger-Selector für dich aus. Falls du das Menü lieber von einem anderen Element öffnen möchtest, kannst du das Ziel im Veröffentlichungsbereich überschreiben.

---

## Abrechnung

Navi+ auf Wix wird über **Wix** abgerechnet — eine kostenlose Stufe plus **Starter-, Business- und Elite**-Pläne, zusammen mit deinem Wix-Abonnement berechnet.
