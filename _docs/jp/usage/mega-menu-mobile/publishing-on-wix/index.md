# メガメニュー（モバイル） — Wix で公開

Navi+ は Wix App Market の**ネイティブアプリ**として Wix で動作します。**モバイルメガメニュー**は、サイトのモバイルメニュー（ハンバーガー）ボタンから開きます。Wix では CSS セレクターを記述する必要はありません: Navi+ は**ハンバーガートリガーを自動入力**します。

> 他のプラットフォーム: [Shopify で公開]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publishing-on-shopify/)、[WordPress で公開]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publish-on-wordpress/)、または [Squarespace / Webflow / その他]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publish-on-wordpress-woocommerce-wix-others/)をご覧ください。

---

## ステップ

1. **[Wix App Market](https://www.wix.com/app-market) から Navi+ をインストール** — Wix ダッシュボード内で開き、サイトに既に接続されています。
2. **モバイルメガメニューを構築** — [メガメニュー（モバイル） — 使い方]({{ site.baseurl }}/docs/usage/mega-menu-mobile/how-to-use/)をご覧ください。
3. **公開** — エディターの公開パネルが既存のハンバーガーボタンをターゲット設定します。公開してください（ステータス: 公開）。

Navi+ は Wix の Embedded Script 経由で自動的に埋め込まれ、トリガーが自動的に接続されます — コード不要、テーマ編集不要。

---

## トリガーは自動

モバイルメガメニューはボタンから開くため、Navi+ がどのボタンかを知る必要があります。Wix サイトは同じ基盤構造（「Thunderbolt」ランタイム）を共有するため、**Navi+ は既にモバイルメニューボタンを認識**し、トリガーセレクターを自動入力します。別の要素からメニューを開きたい場合は、公開パネルでターゲットをオーバーライドできます。

---

## 請求

Wix 上の Navi+ は **Wix** 経由で請求されます — 無料ティアプラス **Starter、Business、Elite** プラン、Wix サブスクリプションと合わせて請求されます。
