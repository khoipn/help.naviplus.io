# Wix で公開

> 💡 Wix での Navi+ が初めてですか？ naviplus.io の [Wix での Navi+ の概要](https://naviplus.io/jp/blogs/compare/topic/naviplus-on-wix/) をご覧ください。

Navi+ は Wix App Market の**ネイティブアプリ**として Wix で動作します。**グリッドメニュー**はセクションメニュー — タップ可能なタイルのブロックで、ページ内に配置することも、ナビゲーションに接続することもできます。Wix では CSS セレクターを記述する必要はありません: Navi+ は**プレイスメントセレクターを自動入力**します。

> 他のプラットフォーム: [Shopify で公開]({{ site.baseurl }}/docs/usage/grid-menu/publishing-on-shopify/)、[WordPress で公開]({{ site.baseurl }}/docs/usage/grid-menu/publish-on-wordpress/)、または [Squarespace / Webflow / その他]({{ site.baseurl }}/docs/usage/grid-menu/publish-on-wordpress-woocommerce-wix-others/)をご覧ください。

---

## ステップ

1. **[Wix App Market](https://www.wix.com/app-market) から Navi+ をインストール** — Wix ダッシュボード内で開き、サイトに既に接続されています。
2. **グリッドメニューを構築** — [グリッドメニュー — 使い方]({{ site.baseurl }}/docs/usage/grid-menu/how-to-use/)をご覧ください。
3. **プレイスメントを選択して公開** — グリッドが表示される場所を選択（ターゲットに挿入するか、ナビゲーションに接続するか）してから、公開してください（ステータス: 公開）。

Navi+ は Wix の Embedded Script 経由で自動的に埋め込まれ、プレイスメントが自動的に適用されます — コード不要、テーマ編集不要。

---

## プレイスメントは自動

グリッドメニューはサイト上の特定の場所に配置されるため、Navi+ が配置する場所を知る必要があります。Wix サイトは同じ基盤構造（「Thunderbolt」ランタイム）を共有するため、**Navi+ は既にヘッダーとメインコンテンツエリアを認識**し、プレイスメントセレクターを自動入力します。公開パネルで**挿入**または**置き換える**を選択してください — CSS を記述する必要はありません。

---

## 請求

Wix 上の Navi+ は **Wix** 経由で請求されます — 無料ティアプラス **Starter、Business、Elite** プラン、Wix サブスクリプションと合わせて請求されます。
