# Wix で公開

> 💡 Wix での Navi+ が初めてですか？ naviplus.io の [Wix での Navi+ の概要](https://naviplus.io/jp/blogs/compare/topic/naviplus-on-wix/) をご覧ください。

Navi+ は Wix App Market の**ネイティブアプリ**として Wix で動作します。**デスクトップメガメニュー**は、サイトのメインナビゲーションバーに接続されるか、置き換えます。Wix では CSS セレクターを記述する必要はありません: Navi+ は**プレイスメントセレクターを自動入力**します。

> 他のプラットフォーム: [Shopify で公開]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publishing-on-shopify/)、[WordPress で公開]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publish-on-wordpress/)、または [Squarespace / Webflow / その他]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publish-on-wordpress-woocommerce-wix-others/)をご覧ください。

---

## ステップ

1. **[Wix App Market](https://www.wix.com/app-market) から Navi+ をインストール** — Wix ダッシュボード内で開き、サイトに既に接続されています。
2. **メガメニューを構築** — [メガメニュー（デスクトップ） — 使い方]({{ site.baseurl }}/docs/usage/mega-menu-desktop/how-to-use/)をご覧ください。
3. **プレイスメントを選択して公開** — エディターの公開パネルで、ネイティブメニューを**置き換える**か、メガメニューを**挿入する**かを選択してから、公開してください（ステータス: 公開）。

Navi+ は Wix の Embedded Script 経由で自動的に埋め込まれ、プレイスメントが自動的に適用されます — コード不要、テーマ編集不要。

---

## プレイスメントセレクターは自動

メガメニューはサイトのヘッダーに接続されるため、Navi+ がどこに配置するかを知る必要があります。Wix サイトはすべて同じ基盤構造（「Thunderbolt」ランタイム）を共有するため、**Navi+ は既にヘッダーとメインメニュー要素を認識**し、プレイスメントセレクターを自動入力します。公開パネルで**置き換える**または**挿入**を選択するだけです — CSS を記述する必要はなく、テーマコードを編集する必要もありません。

---

## 請求

Wix 上の Navi+ は **Wix** 経由で請求されます — 無料ティアプラス **Starter、Business、Elite** プラン、Wix サブスクリプションと合わせて請求されます。
