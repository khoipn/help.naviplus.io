# Navi+ menu not showing on a Shopify Canvas theme

If your store uses a theme created or edited in Shopify's new **Canvas** and your Navi+ menu has disappeared (or never appeared), this is the most likely reason.

## Why it happens

Canvas is Shopify's new way to design a store together with Sidekick. Right now, Canvas does **not** support theme app extensions, which means:

* App blocks and app embeds (including the **Navi+ On all page** embed) **cannot be added or configured** in a theme created or duplicated in Canvas.
* A Canvas theme does not appear in the theme list that apps receive, so Navi+ cannot see it.

This is a current limitation of Canvas on Shopify's side. It is **not** caused by your Navi+ menu or settings, and your menus are safe — nothing was deleted or changed.

Shopify has said that it plans to add support for theme app extensions in Canvas, and that apps do not need to change anything for it to work. We do not have a release date, so please check Shopify's announcements for updates.

## What you can do today

1. **Check whether your live theme is a Canvas theme.** In Shopify admin, go to **Online Store → Themes**. Themes with a Canvas badge can only be opened in Canvas.
2. **Use a regular theme for your live store.** Publish a theme that was not created in Canvas (for example, your previous theme or a fresh copy of it) and turn on the **Navi+ On all page** app embed in the theme editor as usual.
3. **Keep your Navi+ menus as they are.** Once Canvas supports app embeds, you can enable Navi+ again without rebuilding anything.

If the menu is still missing on a regular theme, see [Why is Navi+ menu not displayed on my website?](/docs/frequently-asked-questions/why-navi-not-display/).

## Using Sidekick with Navi+

Shopify Sidekick cannot answer questions about Navi+ or edit Navi+ menus yet. Please create and edit your menus in the Navi+ app as usual. If this changes, we will update this page.
