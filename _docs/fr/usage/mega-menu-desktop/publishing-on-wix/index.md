# Mega Menu (Bureau) — Publier sur Wix

Navi+ fonctionne sur Wix en tant qu'**application native du Wix App Market**. Un **Mega Menu de bureau** s'attache à — ou remplace — la barre de navigation principale de votre site. Sur Wix, vous n'écrivez pas de sélecteurs CSS : Navi+ **remplit automatiquement les sélecteurs de placement pour vous**.

> Autres plateformes : voir [Publier sur Shopify]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publishing-on-shopify/), [Publier sur WordPress]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publish-on-wordpress/), ou [Squarespace / Webflow / autres]({{ site.baseurl }}/docs/usage/mega-menu-desktop/publish-on-wordpress-woocommerce-wix-others/).

---

## Étapes

1. **Installez Navi+ depuis le [Wix App Market](https://www.wix.com/app-market)** — il s'ouvre à l'intérieur de votre tableau de bord Wix, déjà connecté à votre site.
2. **Créez votre Mega Menu** — voir [Mega Menu (Bureau) — Comment l'utiliser]({{ site.baseurl }}/docs/usage/mega-menu-desktop/how-to-use/).
3. **Choisissez le placement et publiez** — dans le panneau de publication de l'éditeur, choisissez de **remplacer** votre menu natif ou **insérer** le Mega Menu à côté, puis publiez (statut : Publié).

Navi+ s'intègre automatiquement via le Script intégré de Wix et applique le placement automatiquement — pas de code, pas de modification de thème.

---

## Les sélecteurs de placement sont automatiques

Parce qu'un Mega Menu s'attache à l'en-tête de votre site, Navi+ doit savoir où. Tous les sites Wix partagent la même structure sous-jacente (le runtime « Thunderbolt »), donc **Navi+ connaît déjà votre en-tête et les éléments du menu principal** et remplit les sélecteurs de placement pour vous. Vous choisissez simplement **remplacer** ou **insérer** dans le panneau de publication — il n'y a pas de CSS à écrire et aucun code de thème à modifier.
