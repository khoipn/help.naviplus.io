# Publier sur Wix

> 💡 Nouveau sur Navi+ pour Wix ? Voir la [présentation de Navi+ sur Wix](https://naviplus.io/fr/blogs/compare/topic/naviplus-on-wix/) sur naviplus.io.

Navi+ fonctionne sur Wix en tant qu'**application native du Wix App Market**. Un **Mega Menu mobile** s'ouvre depuis le bouton de menu mobile (hamburger) de votre site. Sur Wix, vous n'écrivez pas de sélecteurs CSS : Navi+ **remplit automatiquement le déclencheur hamburger pour vous**.

> Autres plateformes : voir [Publier sur Shopify]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publishing-on-shopify/), [Publier sur WordPress]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publish-on-wordpress/), ou [Squarespace / Webflow / autres]({{ site.baseurl }}/docs/usage/mega-menu-mobile/publish-on-wordpress-woocommerce-wix-others/).

---

## Étapes

1. **Installez Navi+ depuis le [Wix App Market](https://www.wix.com/app-market)** — il s'ouvre à l'intérieur de votre tableau de bord Wix, déjà connecté à votre site.
2. **Créez votre Mega Menu mobile** — voir [Mega Menu (Mobile) — Comment l'utiliser]({{ site.baseurl }}/docs/usage/mega-menu-mobile/how-to-use/).
3. **Publiez** — le panneau de publication de l'éditeur cible votre bouton hamburger existant pour vous ; publiez simplement (statut : Publié).

Navi+ s'intègre automatiquement via le Script intégré de Wix et câble le déclencheur automatiquement — pas de code, pas de modification de thème.

---

## Le déclencheur est automatique

Parce qu'un Mega Menu mobile s'ouvre depuis un bouton, Navi+ doit savoir lequel. Les sites Wix partagent la même structure sous-jacente (le runtime « Thunderbolt »), donc **Navi+ connaît déjà votre bouton de menu mobile** et remplit le sélecteur de déclenchement pour vous. Si vous préférez ouvrir le menu depuis un élément différent, vous pouvez remplacer la cible dans le panneau de publication.
