# Publier sur Wix

> 💡 Nouveau sur Navi+ pour Wix ? Voir la [présentation de Navi+ sur Wix](https://naviplus.io/fr/blogs/compare/topic/naviplus-on-wix/) sur naviplus.io.

Navi+ fonctionne sur Wix en tant qu'**application native du Wix App Market**. Un **Grid Menu** est un menu de section — un bloc de tuiles appuyables que vous placez à l'intérieur d'une page ou attachez à votre navigation. Sur Wix, vous n'écrivez pas de sélecteurs CSS : Navi+ **remplit automatiquement les sélecteurs de placement pour vous**.

> Autres plateformes : voir [Publier sur Shopify]({{ site.baseurl }}/docs/usage/grid-menu/publishing-on-shopify/), [Publier sur WordPress]({{ site.baseurl }}/docs/usage/grid-menu/publish-on-wordpress/), ou [Squarespace / Webflow / autres]({{ site.baseurl }}/docs/usage/grid-menu/publish-on-wordpress-woocommerce-wix-others/).

---

## Étapes

1. **Installez Navi+ depuis le [Wix App Market](https://www.wix.com/app-market)** — il s'ouvre à l'intérieur de votre tableau de bord Wix, déjà connecté à votre site.
2. **Créez votre Grid Menu** — voir [Grid Menu — Comment l'utiliser]({{ site.baseurl }}/docs/usage/grid-menu/how-to-use/).
3. **Choisissez le placement et publiez** — sélectionnez où la grille doit apparaître (insérer sur une cible, ou attacher à votre navigation), puis publiez (statut : Publié).

Navi+ s'intègre automatiquement via le Script intégré de Wix et applique le placement automatiquement — pas de code, pas de modification de thème.

---

## Le placement est automatique

Parce qu'un Grid Menu est placé à un endroit sur votre site, Navi+ doit savoir où. Les sites Wix partagent la même structure sous-jacente (le runtime « Thunderbolt »), donc **Navi+ connaît déjà votre en-tête et vos zones de contenu principal** et remplit les sélecteurs de placement pour vous. Choisissez **insérer** ou **remplacer** dans le panneau de publication — il n'y a pas de CSS à écrire.
